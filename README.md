# Анализ продаж Northwind (1996–1997)

## Описание проекта
Анализ выручки и динамики продаж по категориям товаров на основе классической базы данных Northwind.
Цель — выявить ключевые категории-лидеры и аутсайдеры, а также сезонные пики для формирования рекомендаций по управлению ассортиментом.
## Инструменты
- PostgreSQL (SQL-запросы)-написание SQL-запросов для выгрузки и агрегации данных
- Python (pandas, matplotlib)-обработака данных, построение графиков динамики и тендеров
- DBeaver (экспорт данных)-работа с базой данных и экспорт результатов

## Результаты
- Лидер по выручке за период: **Beverages** (всего $99464.50)
- Аутсайдер: **Grains/Cereals** ($22327.75)-почти в 4.5 раза меньше лидера
- Пик продаж пришёлся на **январь 1997 года**, что может указывать на пост-праздничный спрос
- Построен график динамики продаж топ-5 категорий, визуализирующий тренды
  
## Python-код с графиками
Ноутбук: `northwind_analysis.ipynb`(pandas, matplotlib, seaborn) - с полным кодом обработки и визуализации на Pyton

## Файлы
- `sql_query.sql` - запрос с JOIN и GROUP BY для извлечения данных о продажах
- `sales_by_month_category.csv` - выгруженные данные для анализа
